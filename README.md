## Project Overview

This repository contains a comprehensive data visualization pipeline applied to the Titanic passenger dataset. The analysis demonstrates core concepts of exploratory data analysis (EDA), comparing static plotting engines (Matplotlib and Seaborn) with interactive graphing frameworks (Plotly Express).

The primary objective is to evaluate demographic distributions, survival metrics, and feature relationships while justifying chart choices based on specific analytical and business contexts.
